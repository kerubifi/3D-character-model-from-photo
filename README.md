## 📖 О проекте

**3D Character Model from Photo** — это исследовательский проект в области компьютерного зрения и 3D-реконструкции, который превращает обычную фотографию человека в полноценную трёхмерную модель.

В отличие от традиционных методов 3D-моделирования, требующих нескольких ракурсов или специального оборудования, этот проект использует современные нейросетевые архитектуры (PIFuHD) для восстановления объёмной геометрии человека всего по одному изображению.

Проект реализован на Python с использованием PyTorch и OpenCV, объединяя мощь глубокого обучения с удобным графическим интерфейсом для создания профессиональных 3D-моделей.

## 🔥 Ключевые особенности

**🧠 Нейросетевая реконструкция**
Архитектура PIFuHD от Facebook Research. Высокоточное восстановление геометрии.

**📸 Реконструкция из одного фото**
Достаточно одной фотографии человека. Автоматический анализ позы, освещения и контуров тела.

**✂️ Умное обрезание (Smart Rect)**
Автоопределение границ человека. Исключение фонового шума.

**🎚 Многовариантное качество**
- **Быстрое (128)** — 10-15 секунд, ~2 MB
- **Среднее (256)** — 30-60 секунд, ~8 MB
- **Высокое (512)** — 2-3 минуты, ~25 MB

**🖥 Интерактивный GUI**
Выбор фото с предпросмотром. Настройка параметров. Отслеживание прогресса.

**💾 Поддержка форматов**
Сохранение в **OBJ**. Совместимость с Blender, MeshLab, 3D Viewer.

## ⚙️ Как это работает

**1. Загрузка и предобработка изображения**
Пользователь выбирает фотографию через графический интерфейс. Система анализирует размер, разрешение и качество изображения.

**2. Автоопределение границ (Smart Rect)**

Анализ изображения → Детекция контуров → Определение bounding box → Создание rect файла с координатами человека

**3. Загрузка нейросети**
PyTorch загружает предобученную модель PIFuHD с весами, обученными на тысячах 3D-сканов людей.

**4. 3D-реконструкция**

Фотография → Нейросетевая сеть → Октавное дерево → Марширующие кубы → 3D-сетка → OBJ файл


**5. Визуализация результата**
Готовая модель сохраняется в папке `results/pifuhd_final/recon/result_test_256.obj`

## 🚀 Запуск проекта

**Пошаговая установка**

**1. Клонирование репозитория**

```bash
git clone https://github.com/kerubifi/3D-character-model-from-photo.git
cd 3D-character-model-from-photo
```

**2. Создание виртуального окружения**

```bash
python -m venv venv_pifuhd
venv_pifuhd\Scripts\activate.bat
```

**3. Установка PyTorch с CUDA 11.0**

```bash
pip install torch==1.7.1+cu110 torchvision==0.8.2+cu110 -f https://download.pytorch.org/whl/torch_stable.html
```

**4. Установка остальных библиотек**

```bash
pip install opencv-python pillow scipy tqdm pyrender trimesh imageio matplotlib scikit-image
```

**5. Скачивание модели нейросети (1.44 GB)**

```bash
mkdir checkpoints
python -c "import urllib.request; urllib.request.urlretrieve('https://dl.fbaipublicfiles.com/pifuhd/checkpoints/pifuhd.pt', 'checkpoints/pifuhd.pt')"
```

**6. Запуск GUI**

```bash
python pifuhd_gui.py
```

## 🎮 Быстрый старт через GUI

1. Нажмите кнопку "Обзор" и выберите фотографию
2. Выберите качество: Быстрое (128) / Среднее (256) / Высокое (512)
3. Нажмите "СОЗДАТЬ 3D МОДЕЛЬ"
4. Дождитесь завершения обработки (30-90 секунд)
5. Откройте папку с результатом и загрузите OBJ файл
